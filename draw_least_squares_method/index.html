完整使用教程

在左侧输入框中每行写一条命令，点击“生成图”即可在右侧绘制散点和线性拟合线。
  • x: x 轴数据，后面跟空格分隔数字。
  • y: y 轴数据，后面跟空格分隔数字。
  • xparse: x 数据变换表达式，使用变量 $ 代表当前值。例如 xparse $ * 2 + 1。
  • yparse: y 数据变换表达式，使用变量 $。
  • xname: x 轴标题文字。
  • yname: y 轴标题文字。
  • bgcolor: 图表背景色，支持 CSS 颜色格式，例如 #fdfaf2、rgb(240,248,255)、lightyellow。
  • linecolor: 拟合线颜色，支持 CSS 颜色格式。
  • pointcolor: 散点颜色，支持 CSS 颜色格式。
示例输入：
x -2 -1 0 1 2 3
y -1 0.2 1.1 2.2 2.9 4.1
xparse $ * 1
yparse $ * 1
xname 时间 t
yname 位移 s
bgcolor #fffdf6
linecolor #d97706
pointcolor #0f766e
  • 若 x 和 y 数量不一致，系统会自动按较短长度配对并提示忽略数量。
  • “重置视图”会恢复默认缩放和平移。
  • “下载图片”会导出当前画布为 PNG 图片。
